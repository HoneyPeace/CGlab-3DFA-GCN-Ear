### 📊 5. 평가 (Evaluation)

```
현재
python eval_all.py --run_id 6 --sigma 5 --num_points 2048 --Eval_DataType test --regression_point_num 10

기존
python eval_all.py --dataset Ear296_Korean --sigma 5 --num_points 2048 --regression_point_num 10 --Eval_DataType sample
```

sample, train, test 선택

| 파라미터 | 역할 | 영향 받는 모듈/단계 |
| --- | --- | --- |
| `dataset` | 사용할 데이터셋 선택 | `main_sample`, `calculateHeatMap` |
| `number_point` | FPS로 추출할 포인트 수 | 샘플링 (FPS) |
| `seed` | 재현 가능성 보장 | 모든 난수 관련 |
| `sigma` | 가우시안 히트맵 폭 조절 | `Gaussian_Heatmap()` → 히트맵 분포 직접 결정 |
| `sample_way` | FPS 방식으로 샘플링 | `main_sample()` |
| **`regression_point_num`** | **히트맵 후처리 시 top-k 수 선택** | 🔥 `landmark_regression()` 단계에서 사용됨 |
| **`k`** | PAConv에서 이웃 수 | 🔥 GCN 학습 시 point graph 구성에 영향 |
